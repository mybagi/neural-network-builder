# 神经网络搭建实验室

下载或克隆本仓库，保留文件夹结构，再用浏览器打开 `index.html`。游戏可离线运行。部署到静态站点时，一并保留 `typography.css`、`fonts/`、`locale.js` 和 `vendor/`。

选择实验，在工作台加入隐藏层、选中神经元、接通上一层的输入，再调整连接权重和偏置。点击测试样本可看到每个节点的输出，以及所选神经元的加权求和和激活过程。点“检查全部样本”提交当前网络。

三关分别检验或门、异或门和连续信号限幅。输出由当前连接、权重、偏置和激活函数实时计算。右上角可切换 English、简体中文、繁體中文。浏览器允许本地存储时，页面会记住所选语言和已通过的关卡。

可用 Tab 在控制项间移动，用空格接线，用方向键调整已接通的权重和偏置。
